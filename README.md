# 🪪 香港入境处预约配额监控

实时追踪香港入境事务处**换领身份证**预约配额，新名额放出时 **飞书群 + 飞书私聊 + 邮件** 自动通知。

---

## 📱 方式一：加入飞书群（推荐）

机器人自动推送配额变化，**消息秒达**，加群即用，无需任何配置。

> 📖 **[群信息 & 加群方式](https://scn7uo58gnuo.feishu.cn/wiki/QSFlwcMBmil7sGkZRBTcAWqwnCf)**（多群方案，群满自动分流）

### 💬 方式二：飞书私聊订阅

如果不想加群，也可以**按日期过滤**，仅接收你关注日期的通知：

1. [私聊机器人「HKID放号自动监测」](https://applink.feishu.cn/T98uc8RbxI8c)（发送任意消息即可触发）
2. 机器人会回复交互卡片，支持：
   - 📅 **订阅特定日期** — 只关注你预约的那天
   - 🔔 **订阅全部日期** — 所有放号都通知
   - 📊 **查看 / 修改 / 取消订阅**
3. 也可以直接回复日期一键订阅，例如 `08/15, 08/20-08/25`

> 💡 机器人私聊有 1-2 秒延迟，着急的话推荐进群。

---

## 📧 方式三：邮件订阅（即将下架）

在看板页面输入邮箱点击「订阅」，配额放出时自动收到 HTML 通知邮件。

> ⚠️ 邮件因批量发送易被拦截，无法保证实时送达，**不推荐此渠道**，后期将下架。
>
> ⚠️ 中国内地用户需科学上网才能提交。订阅成功后接收邮件不受影响，无需持续 VPN。

---

## 📨 通知流程

检测到新配额放出时，按以下顺序推送：

> **群聊广播**（多群并行）→ **私聊 DM**（并行，仅推送给匹配日期的订阅者）→ **邮件**（逐封发送）

飞书群和私聊几乎同时到达，邮件因批量 SMTP 发送排在最后。

## 🔒 隐私与安全

- 订阅者邮箱和飞书用户数据使用 **AES-256-GCM 加密存储**，仓库中不可读
- 仅读取入境处**公开发布**的配额数据
- 邮件退订链接支持一键退订
