# 🪪 香港入境处预约配额监控

实时追踪香港入境事务处**换领身份证**预约配额，新名额放出时 **飞书群 + 飞书私聊 + 邮件** 自动通知。

> **✨ 无需懂代码** — 打开网页看板即可查询，或加入飞书群自动接收通知。

### 💬 飞书私聊按日期过滤（新功能）

群聊广播是全量推送，如果你只想看**特定日期**的通知，可以私聊机器人按日期订阅：

1. 在飞书里私聊「**HKID放号自动监测**」机器人
2. 机器人会回复交互卡片，支持：
   - 📅 **订阅特定日期** — 只关注你预约的那天
   - 🔔 **订阅全部日期** — 所有放号都通知
   - 📊 **查看 / 修改 / 取消订阅**
3. 也可以直接回复日期一键订阅，例如 `08/15, 08/20-08/25`

> 💡 私聊过滤是额外功能，不订阅的话和以前完全一样，群聊广播不受影响。

## 📧 方式二：邮件订阅

在看板页面输入邮箱点击「订阅」，配额放出时自动收到 HTML 通知邮件，内含变化详情、预约链接、飞书群二维码，底部附带一键退订。

> ⚠️ **中国内地用户请注意**：邮件订阅/退订功能依赖 Cloudflare Worker，在内地需科学上网才能提交。订阅成功后**接收邮件不受影响**，无需持续 VPN。飞书群通知无此限制，内地用户推荐优先使用飞书群。
